# Website direction

## THESIS
A quiet studio practice sheet makes focus feel like a deliberate ritual, not productivity theater.

## OWN-WORLD
Warm paper (#f6f3eb), vermilion (#bd3c2c), deep green (#233c32), precise ink rules, self-hosted Fraunces display and DM Sans body. Flat editorial materials, no fake texture, no card grid. The real app screenshot provides the object.

## STORY
Introduce the desktop timer, show the actual interface, explain cycles and statistics, let the visitor try an explicitly labeled browser demo, then provide honest platform-specific build instructions.

## FIRST VIEWPORT
Large left-aligned editorial headline paired with a substantial real desktop screenshot on a clay field. One dominant install action and one source link. Navigation remains quiet. The page must say desktop Pomodoro timer immediately.
